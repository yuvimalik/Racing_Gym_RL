# Archive

This folder preserves project history that is useful for provenance but not part of the primary final-submission path.

- `reports/`: earlier milestone reports, draft slide decks, and older presentation PDFs.
- `dev_notes/`: installation prompts, migration plans, local assistant guidance, and Prime setup notes used during development.
- `prime_runs/`: Prime/cloud training pulls, backup logs, checkpoints, videos, TensorBoard files, and run summaries.

The active final report is in `docs/`, the canonical final slides are in `slides/`, and runnable notebooks are in `notebooks/`.
